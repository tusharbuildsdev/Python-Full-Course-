# Day 08 — Object Oriented Programming

Object-oriented programming: classes, objects, methods, inheritance, lambdas, and modules.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `classes_and_objects.py` — Classes And Objects.
- `inheritance.py` — Inheritance.
- `instance_methods.py` — Instance Methods.
- `lambda_function.py` — Lambda Function.
- `module_basics.py` — Module Basics.

All examples are formatted with the project’s shared Python style.
