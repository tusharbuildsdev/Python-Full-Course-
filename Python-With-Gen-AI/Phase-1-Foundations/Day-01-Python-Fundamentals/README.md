# Day 01 — Python Fundamentals

Python basics: output, variables, numeric values, operators, comments, and naming conventions.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `assignment_operator.py` — Assignment Operator.
- `comments.py` — Comments.
- `hello.py` — Hello.
- `numbers.py` — Numbers.
- `operators.py` — Operators.
- `print.py` — Print.
- `variable_naming.py` — Variable Naming.
- `variables.py` — Variables.

All examples are formatted with the project’s shared Python style.
