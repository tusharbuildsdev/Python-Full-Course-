# Day 13

Building conversational chatbots with single-turn, multi-turn, persona, and full-chat flows.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `chat_loop.py` — Chat Loop.
- `chatbot_full.py` — Chatbot Full.
- `chatbot_persona.py` — Chatbot Persona.
- `chatbot.py` — Chatbot.
- `single_turn.py` — Single Turn.

All examples are formatted with the project’s shared Python style.
