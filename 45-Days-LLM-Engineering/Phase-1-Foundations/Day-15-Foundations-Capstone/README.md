# Day 15 Test

Practical Python mini-projects for validation, billing, OTPs, coupons, and UPI-style flows.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `Coupon_Engine.py` — Coupon Engine.
- `Fake_Cart_&_Bill.py` — Fake Cart & Bill.
- `Fake_logic_system.py` — Fake Logic System.
- `OTP_Engine.py` — OTP Engine.
- `Password_Strength_Checker.py` — Password Strength Checker.
- `Wallet_UPI_Simulator.py` — Wallet UPI Simulator.

All examples are formatted with the project’s shared Python style.
