# Day 11 — API Development Basics

Type hints, Pydantic models, environment variables, and first LLM API calls.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `dotenv_secrets.py` — Dotenv Secrets.
- `first_call.py` — First Call.
- `pydantic_models.py` — Pydantic Models.
- `type_hints.py` — Type Hints.

All examples are formatted with the project’s shared Python style.
