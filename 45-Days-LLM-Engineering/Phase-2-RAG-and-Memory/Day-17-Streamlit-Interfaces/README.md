# Day 17 Streamlit

Streamlit applications for layouts, widgets, files, state, caching, and chat interfaces.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `caching_app.py` — Caching App.
- `chat_app.py` — Chat App.
- `display_app.py` — Display App.
- `hello_app.py` — Hello App.
- `layout_app.py` — Layout App.
- `read_pdf.py` — Read Pdf.
- `read_text_file.py` — Read Text File.
- `state_app.py` — State App.
- `widgets_app.py` — Widgets App.

All examples are formatted with the project’s shared Python style.
