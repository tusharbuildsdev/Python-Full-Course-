# Day 18 — Document Chat

A document-chat application with file loading, chunking, embeddings, retrieval, and an LLM.

## Run a program

Open a terminal in this folder and run:

```powershell
python "<program-file>.py"
```

## Programs

- `app.py` — App.
- `chunker.py` — Chunker.
- `config.py` — Config.
- `file_loader.py` — File Loader.
- `llm.py` — Llm.
- `rag.py` — Rag.
- `vector_store.py` — Vector Store.

All examples are formatted with the project’s shared Python style.
